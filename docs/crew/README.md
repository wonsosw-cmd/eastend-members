# 크루 카페 사용권

크루가 제휴 카페에서 **월 3회 / 1회 15,000원**까지 회사 지원으로 커피를 마실 수 있게 하는 웹앱.
GitHub Pages(화면) + Google Apps Script(백엔드) + 비공개 구글시트(DB) 구조라 서버 비용이 없고,
승인 즉시 모든 화면에 실시간으로 반영된다.

## 화면 3개

| 화면 | 주소 | 쓰는 사람 |
|---|---|---|
| 크루 앱 | https://wonsosw-cmd.github.io/eastend-members/crew/ | 크루 (휴대전화 번호로 로그인) |
| 카페 승인 | https://wonsosw-cmd.github.io/eastend-members/crew/cafe.html | 제휴 카페 직원 **공통** (카페 접속 코드) |
| 관리자 | https://wonsosw-cmd.github.io/eastend-members/crew/admin.html | 본사 (관리자 토큰) |

백엔드는 구글시트 `크루 카페 사용권 DB` + Apps Script `크루 카페 사용권 API`.
토큰은 저장소에 두지 않는다 — Apps Script에서 `setup()`을 실행하면 실행 로그에 다시 찍힌다.

## 사용 흐름

1. 크루가 앱에서 **카페 사용하기** → 4자리 코드 발급 (3분 유효, 1회용)
2. 카페 직원이 공통 주소에서 **코드 입력 → 이름 확인 → 결제 금액 입력 → 승인**
3. 크루 화면이 자동으로 "사용 완료"로 바뀌고, 시트에 기록 + 관리자 집계에 즉시 반영

- 결제 금액이 15,000원 이하 → 전액 회사 지원
- 15,000원 초과 → 15,000원까지만 회사 지원, 나머지는 크루가 카페에서 직접 결제
- 월 한도를 다 쓰면 코드 발급 자체가 막힘 (승인 시점에도 한 번 더 검사)

## 최초 설치 (2026-08-07 완료 — 아래는 재구축용 기록)

1. **구글 시트 생성** — 이름 예: `크루 카페 사용권 DB` (비공개 유지)
2. 시트에서 **확장 프로그램 > Apps Script** → `gas/crew/Code.gs` 내용을 붙여넣고 저장
3. `setup()` 1회 실행 → 실행 로그에 **관리자 토큰 / 카페 토큰**이 찍힘 (복사해 둘 것)
4. **배포 > 새 배포 > 웹 앱**
   - 실행: 나
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 `https://script.google.com/macros/s/.../exec` 복사
5. `docs/crew/config.js`의 `API_URL`에 붙여넣고 커밋 → push
6. 관리자 화면 로그인 → **설정 탭**에서 카페 이름·정책 확인 → **크루 관리 탭**에서 크루 추가

## 운영 메모

- **코드 수정 후**: 배포 > 배포 관리 > (기존 배포) 수정 > 새 버전 — URL이 유지된다
- **카페 접속 코드 변경**: `setCafeToken()` 본문의 값을 고쳐 1회 실행 (재배포 불필요)
- **정책 변경**(월 횟수·1회 한도): 관리자 설정 탭 또는 시트 `설정` 탭 직접 수정
- **개별 크루만 다른 한도**: 크루 관리 탭에서 해당 크루 "월 한도" 지정 (비우면 기본값)
- **잘못 승인된 건**: 관리자 사용 내역 탭에서 **취소** → 그 달 사용 횟수에서 빠짐
- **퇴사자**: 삭제 대신 **중지**를 쓰면 과거 집계가 그대로 남는다

## 시트 구조

- `크루` — 등록일시 / 크루ID / 이름 / 휴대전화 / 소속 / 상태 / 월한도 / 메모
- `사용내역` — 승인일시 / 사용ID / 크루ID / 이름 / 소속 / 카페 / 결제금액 / 회사부담 / 자기부담 / 승인자 / 코드 / 년월 / 상태 / 메모
- `카페` — 카페명 / 상태 / 메모
- `설정` — 월한도 / 1회한도

개인정보(이름·휴대전화)는 시트에만 저장되고 GitHub에는 올라가지 않는다.
